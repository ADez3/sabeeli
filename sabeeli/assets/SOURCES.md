# Bundled data sources and licenses

All files were downloaded from the sources below and only transformed structurally
(JSON reshaping, HTML-tag removal). No Qur'an, hadith or dhikr text was typed or edited by hand.
Reproduce with `tool/data/fetch_raw.sh` followed by the `tool/data/build_*.py` scripts
(see the header of `fetch_raw.sh`). Raw downloads live in `tool/data/raw/` (git-ignored).

Structural changes applied to the Warsh and Qalun texts (nothing else is touched; ۞, ۩, pause marks
and spacing inside the ayah are kept as published):
- the trailing `U+00A0` + ayah-number glyph (one code point `U+FC00 + n-1`, drawn by the KFGQPC font)
  is removed after checking that it matches `aya_no` (in Warsh 16:123 the glyph has no `U+00A0` before it);
- `U+200F` (right-to-left mark) characters are removed: export artifacts, 14 per text, each placed
  just before the word for "the Prophet" (`U+200D` would be removed too; none occur);
- leading/trailing whitespace is trimmed (two Qalun records, 2:5 and 17:67, start with a space).
These two riwayat do not count the basmala of al-Fatihah as an ayah (6214 ayahs in total).
